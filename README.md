# 📚 DocuMind — AI-Powered PDF Research Assistant

DocuMind is an AI-powered PDF question-answering application that allows users to upload research papers, academic notes, reports, and other PDF documents, then ask questions and receive answers based on their contents.

The project combines **Natural Language Processing (NLP), semantic search, vector similarity, and generative AI** to make document research easier.

## ✨ Features

* **PDF Upload:** Upload one or multiple PDF documents.
* **Text Extraction:** Extract readable text from PDF pages.
* **Text Chunking:** Split large documents into smaller passages for efficient retrieval.
* **Semantic Search:** Find passages related to a question based on meaning rather than exact keyword matches.
* **AI-Powered Answers:** Generate answers using Google's FLAN-T5 model.
* **Source References:** Display the PDF filename and page number of retrieved passages.
* **Relevance Filtering:** Filter out passages with low similarity scores.
* **Interactive Interface:** Use a simple web interface built with Gradio.
* **Google Colab Support:** Run the project without setting up a local development environment.

## ⚙️ How It Works

1. **Upload:** The user uploads one or more PDF documents.
2. **Extract:** DocuMind extracts text from each PDF page.
3. **Chunk:** The extracted text is divided into smaller passages.
4. **Embed:** Sentence Transformers converts each passage into a numerical vector.
5. **Index:** FAISS stores the vectors for efficient similarity search.
6. **Retrieve:** When the user asks a question, DocuMind retrieves the most relevant passages.
7. **Generate:** FLAN-T5 generates an answer using the retrieved context.
8. **Display:** The application displays the answer and associated source pages.

## 🚀 Getting Started

### Option 1: Run in Google Colab

1. Open [Google Colab](https://colab.research.google.com/).
2. Create a new notebook.
3. Copy the project code into a notebook cell.
4. Run the cell and wait for the dependencies and AI models to load.
5. Open the Gradio link generated by the application.
6. Upload your PDF documents and click **Process Documents**.
7. Enter a question and click **Ask DocuMind**.

### Option 2: Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/DocuMind.git
cd DocuMind
```

Open `DocuMind.ipynb` in Google Colab and run the notebook.

## ⚠️ Limitations

* The current implementation works with text-based PDFs. Scanned documents may require OCR.
* Answer quality depends on the relevance of the retrieved passages and the language model.
* Similarity scores indicate textual relevance, not whether a passage definitively answers a question.
* The model may occasionally generate incorrect or incomplete answers. Always verify important information against the original document.
* Documents and search indexes are stored in the active runtime and may need to be reprocessed after a session ends.
* Large PDFs may require additional memory and processing time.
